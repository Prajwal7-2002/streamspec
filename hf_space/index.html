The Concatenation Mechanism

In classic speculative decoding, an extra target forward sweep is needed to sync logits after emitting a bonus or resampled token.

`StreamSpec` eliminates this by prepending the trailing accepted token directly into the next round's draft tensor:

X_sweep = [ x_trailing || x_draft_1, x_draft_2, ..., x_draft_K ]

Target streams all layers **exactly once per round**. The first logit \(\hat{y}_0\) synchronizes state, while \(\hat{y}_{1 \dots K}\) verify candidate tokens simultaneously in GEMM.

Theorem: Zero Reasoning Degradation Under Rejection Sampling

Let \( q(x) \) be the speculative draft distribution and \( p(x) \) be the giant target model distribution. The rejection sampling acceptance probability is:

α(x) = min( 1, p(x) / q(x) )

If candidate token \( x \) is rejected, a replacement is sampled from the normalized residual distribution:

p_resample(x) = max(0, p(x) - q(x)) / ∑_x' max(0, p(x') - q(x'))

First Principles Marginal Emission Proof:

P(emit x) = P(accepted x) + P(rejected) × p_resample(x)
P(emit x) = q(x) × min(1, p(x)/q(x)) + P_reject × [ max(0, p(x) - q(x)) / P_reject ]
P(emit x) = min(q(x), p(x)) + max(0, p(x) - q(x))
P(emit x) = p(x) ▪ (Q.E.D.)
